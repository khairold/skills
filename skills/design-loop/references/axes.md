# Review axes

Pick 1–3 per round. Each line: what the reviewer looks for, and when it earns a round.

## Build quality
- **Bugs and layout.** Overlap, clipping, overflow, scrollbars, broken interactions, console
  errors, numbers that disagree between views. First round, and after any large change.
- **Responsive / sizes.** Every view at the sizes it will really be seen at (e.g. 1920x1080,
  1600x900, 1280x720, phone width). When the venue or device is unknown.

## Craft
- **Design craft against a benchmark.** Hierarchy, illustration richness, typography, whitespace
  balance, consistent components, slide-to-slide rhythm, motion that tells a story. Give the
  reviewer the benchmark and ask for side-by-side comparison. After the build is clean.
- **Motion and builds.** Do steps reveal in a sensible order, does each step change something,
  does the first frame show the shape of what is coming, is reduced motion respected.
- **Brand.** Colours, type, logo use against the brand guide.

## Message
- **Story flow.** One message per view, each sets up the next, the ending asks for something.
- **Audience fit.** Read as the actual audience: jargon, "what's in it for me", plain language.
- **Critical stakeholder.** Role-play 2–3 named skeptics (the sponsor, the approver, the user).
  What would they push back on that the work doesn't answer? Before any decision meeting.
- **Accuracy against sources.** Every claim checked against the source files; overstatement
  flagged. Whenever facts come from documents.
- **10-second test.** Glance at each view for 10 seconds: does the point land?

## Delivery
- **Presenter run-through.** Drive it with real key and click events: every path forward and
  back, clicker keys (PageDown/PageUp), focus traps in forms, hints, deep links. Before a live
  showing.
- **Screen-share and projector legibility.** Downscale to ~960x540 with heavy JPEG compression
  (Teams/Meet), and a washed-out, low-contrast version (projector). Smallest text, faint greys,
  meaning carried only by colour. Before a live or remote showing.
- **Accessibility.** Contrast ratios, colour-blind safety, minimum sizes, keyboard use, labels.
- **Standalone reading.** Does it make sense forwarded with no presenter? Speaker notes? PDF or
  print export with every build visible.
